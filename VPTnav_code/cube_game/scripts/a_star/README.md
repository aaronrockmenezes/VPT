# A* Scripts

Active A* rollout code for cube-game generation.

- `A_star_data_collector.py` — production rollout collector used by
  `job_array/a_star/a_star_launcher.py`.
- `A_star_agent.py` — A* agent implementation.
- `A_star_automatic_agent.py` — automatic A* agent entrypoint.
- `compile_dataset.sh` — legacy A* compile helper kept with A* scripts.

Normal VPTnav generation scripts live in `../vptnav/`.
