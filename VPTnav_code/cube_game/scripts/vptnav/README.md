# Normal VPTnav Scripts

Active non-A* cube-game generation utilities.

- `keyboard_agent.py` — normal VPT1/VPTnav generation driver.
- `vpt2_keyboard_agent.py` — VPT2 generation driver.
- `count_saved_envs.py` — camera-move saved-env counter.
- `list_envs.py`, `random_agent.py`, `zero_agent.py` — small utility agents.

A* rollout scripts live in `../a_star/`. Current multi-GPU dispatch lives under
`VPTnav_code/cube_game/job_array/normal_vptnav/`, not in this directory.
