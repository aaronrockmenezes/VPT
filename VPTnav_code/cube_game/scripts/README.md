# Cube Game Scripts

Active cube-game scripts are split by workflow:

- `a_star/` — A* rollout agents and collectors.
- `vptnav/` — normal VPTnav/VPT1/VPT2 generation agents and counters.
- `sb3/`, `skrl/` — legacy RL train/play scripts kept for reference.

Old linear-probe shell launchers were removed from this directory. Use the
root-level `scripts/` workflow for current probing and fine-tuning commands.
